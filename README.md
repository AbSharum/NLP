# NLP Coursework

Problem sets and a final research project from a Natural Language Processing course.

## Contents

- `Project/` — Final project: a LaTeX research report/proposal (with bibliography) covering sentiment analysis, language generation, contextual memory, and transformers, plus exploratory code in `Code/Data.ipynb`.
- `PS1/` — `UAStringParser.java`, a string parsing exercise.
- `PS2/application/` — An n-gram based text generation bot (`bot.py`, `grams.py`, `main.py`) trained on Shakespeare text.

## Stack

Python (Jupyter), Java, LaTeX.

## Running

For `PS2/application`:

```
python main.py
```

For `PS1`, compile and run `UAStringParser.java` directly.
